# wezterm

My personal WezTerm config. Theming and quality-of-life tweaks.

## Dependencies

| Dependency | Install |
|---|---|
| WezTerm | `brew install --cask wezterm` |
| Hack Nerd Font | `brew install --cask font-hack-nerd-font` |

## Notes

- Color scheme: `rose-pine-moon`
- Font: Hack Nerd Font
- Tab bar hidden when there's only one tab
- Window background blur/opacity and font size tuned per-OS (macOS/Windows)
- Open config file: `code ~/.wezterm.lua`
